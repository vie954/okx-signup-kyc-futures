## 준비물: 가입 전에 챙길 네 가지

1. **장기적으로 접근 가능한 이메일**. 시스템 알림, 본인 확인, 비밀번호 재설정에 쓰입니다. Outlook, QQ메일, 163메일 같은 개인 메일이면 되고, 임시 메일이나 다른 사람 메일은 안 됩니다.
2. **본인 명의 휴대폰 번호**. 문자 인증을 받을 수 있어야 하고, 이미 다른 계정에 등록된 번호는 쓸 수 없습니다.
3. **신분증**. KYC에서 앞면과 뒷면을 촬영합니다.
4. **OTP 앱**. Google OTP 같은 인증 앱을 미리 설치해 두면 2단계 보안 설정이 한 번에 끝납니다.

## 회원가입: 국가 설정부터 비밀번호까지

앱이든 웹이든 흐름은 같습니다. 앱 기준으로 설명합니다.

**1) Sign up 선택 후 국가/지역 지정.** 여기서 고르는 건 국적이 아니라 현재 상주하는 국가·지역입니다. 여권 발급국이나 일시적인 여행지가 아닙니다. 이 선택이 서비스 주체를 결정하기 때문에, 나중에 KYC나 이용 가능 기능에 영향을 줍니다. 목록에 본인 거주지가 없다면 그 지역은 현재 가입을 지원하지 않는 것이니, 다른 나라를 골라 우회하지 마세요.

**2) 이메일과 레퍼럴 코드 입력.** 이메일 주소를 넣고, 그 아래 레퍼럴 코드 칸에 코드를 적습니다. 앱에서는 이 칸이 접혀 있는 경우가 많아 직접 펼쳐야 합니다. 코드를 넣지 않아도 가입은 진행되지만, 추천 관계는 등록 시점에 입력한 코드로만 확정됩니다. 나중에 추가하는 절차는 없습니다.

**3) 이메일 인증번호 6자리.** 10분 안에 입력해야 합니다. 시간이 지나면 다시 요청해야 합니다.

**4) 휴대폰 번호 등록.** 국가 코드를 고르고 번호를 넣습니다. 국가 코드를 이미 선택했다면 번호 칸에 같은 코드를 또 쓰지 마세요. 흔한 입력 오류입니다.

**5) 문자 인증번호 6자리.** 이것도 10분 안에 입력합니다.

**6) 비밀번호 설정.** 숫자, 문자, 기호, 대소문자를 조합합니다. 다른 사이트와 같은 비밀번호는 피하세요.

여기서 알아둘 제약이 세 가지 있습니다. 이메일 하나당 계정 하나, 휴대폰 번호 하나당 계정 하나입니다. 서브 계정에 휴대폰을 붙일 수는 있지만, 이미 등록된 번호는 안 됩니다. 그리고 계정을 지우고 다시 만들어도 신규 사용자 자격이 되살아나지 않습니다.

## KYC 신원 인증: 앱에서 10~30분

OKX는 신원 인증을 필수로 요구합니다. 웹보다 앱이 빠릅니다.

1. 앱 설치 후 방금 만든 계정으로 로그인
2. 메인 화면의 **Get verified**(인증하기) 선택
3. 신분증 종류 선택 후 앞면·뒷면 촬영
4. 실시간 얼굴 인증
5. 촬영한 신분증 기반으로 인적 사항이 자동 입력됨. 수정할 게 없으면 주소 입력으로 진행
6. 도로명 주소와 우편번호 입력

처리 시간은 공식 수치가 따로 없습니다. 참고로 한 영상 작성자는 보통 10~30분 안에 완료된다고 언급했습니다. 이건 개인 경험이니 심사 상황에 따라 달라질 수 있습니다.

신분증 하나는 계정 하나에만 연결됩니다. 인증이 완료되면 신분증을 바꾸거나 인증을 취소할 수 없습니다. 처음 낼 때 제대로 내야 합니다.

18세 미만은 예외가 없습니다. 보호자 동의, 경제적 사정 같은 이유로도 안 되고, 부모나 다른 사람의 신분 정보를 빌려 등록하는 것도 금지됩니다. 반대로 나이가 많다고 가입이 막히지는 않습니다.

## 입금: USDT를 TRC20으로 넣는 예시

OKX는 해외 거래소라 국내 거래소에서 코인을 전송하는 방식이 흔히 쓰입니다. 아래는 한 영상에서 소개한 예시이고, OKX가 안내하는 유일한 공식 경로는 아닙니다.

1. 국내 거래소(예: 업비트)에서 USDT 매수
2. OKX에서 **Deposit** 선택 → USDT 검색 → 네트워크 **TRC20(Tron)** 선택
3. 생성된 입금 주소 복사
4. 국내 거래소에서 출금 신청, 네트워크는 반드시 **Tron**으로 동일하게 선택, 받는 사람 주소에 복사한 OKX 주소 붙여넣기
5. 출금 신청과 2차 인증 완료

영상 작성자는 약 3분 안에 입금이 완료됐다고 말했지만, 이 역시 개인 경험이고 네트워크 상황에 따라 달라집니다. 수수료와 도착 시간은 전송 화면에 표시되는 값을 확인하세요.

가장 위험한 지점은 네트워크입니다. 보내는 쪽과 받는 쪽 네트워크가 다르면 자산을 잃을 수 있습니다. 주소를 붙여넣은 뒤 네트워크 이름을 한 번 더 눈으로 확인하는 습관이 필요합니다.

## 펀딩 계정에서 트레이딩 계정으로 이체

입금한 자산은 펀딩(Funding) 계정에 들어옵니다. 바로 거래할 수 없고, 트레이딩 계정으로 옮겨야 합니다. 홈 화면 **Assets** → **Transfer** → Funding에서 Trading 선택 → 금액 입력 → **Transfer**를 누르면 됩니다.

## 선물거래: 주문 전에 정할 것들

**Trade → Futures**에서 종목을 고릅니다. BTC 같은 주요 코인부터 시작하는 경우가 많습니다. 주문 전에 마진 모드와 레버리지를 먼저 정합니다.

- **Cross(교차)**: 선물 지갑의 전체 자산으로 포지션을 유지합니다.
- **Isolated(격리)**: 해당 포지션에 배정한 자산만으로 운용합니다.

레버리지 배율은 조절할 수 있고, 처음이라면 낮은 배율에서 시작하는 편이 낫습니다.

주문 방식은 두 가지입니다. **Limit**은 원하는 가격을 지정해 진입하고, **Market**은 현재 시장가로 즉시 진입합니다. 가격 상승을 예상하면 **Long**, 하락을 예상하면 **Short**입니다. 체결되면 화면 아래에서 포지션 정보와 실시간 손익을 볼 수 있습니다.

리스크 관리는 **TPSL**의 **Add**에서 미리 설정합니다. Take Profit에 익절가, Stop Loss에 손절가를 넣으면 차트를 계속 보지 않아도 해당 가격에 포지션이 자동 종료됩니다. 정리하고 싶을 때는 **Close All**로 전체 포지션을 한 번에 닫습니다.

선물은 레버리지를 쓰기 때문에 가격 변동만큼 손실이 커집니다. 주문 전에 수수료, 증거금, 청산 위험을 확인하세요.
